# Second Nature

A cognitive training app with three experiences: **Condition**, **Perceive**, and **Discover**.

## Product direction

- Full-screen mobile-first interface with intentional scene navigation rather than document scrolling.
- Cinematic introductory sequence and responsive ambient visual field.
- Habit conditioning through cue-response practice, logging, user-configurable milestones, and progress tracking.
- Milestones represent training progress, not scientific proof of habit automaticity.

## Deployment

Existing live Vercel project: `second-nature-lab`.
